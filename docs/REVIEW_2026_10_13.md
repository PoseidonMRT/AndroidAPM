新增 `ApmContext.emitInSession` 两个 synthetic overload 是跨独立发布模块的 SDK 交接桥。它保持同步或异步缓存的业务上下文语义，绑定捕获 runtime 的发生身份和进程；最终 module guard 在宿主回调返回后执行。现有公开签名保持，ABI 仅手工追加两项。

Hprof 的 primitive payload 等长零填充用于减少敏感内容，**不会减少文件字节数**；不能把它描述为 60–80% 文件缩减。ART/OEM 的 dump 执行与 Native signal 恢复仍需真实设备验证。

## 审查范围与证据

审查分组覆盖 core 生命周期/交接/聚合/脱敏/IPC/诊断，model/storage/uploader/remote-config，plugin/crash/ANR/memory/slow-method，以及 Network、FPS、Launch、IO、Battery、SQLite、WebView、IPC、Thread、GC、Render、Trace 和 OTel 映射。对已有协议、容量、同意撤回及 ABI 回归做针对性复核；没有为未复现的推测增加功能。

平台语义依据为 [WebViewClient 官方 API](https://developer.android.com/reference/android/webkit/WebViewClient)、[Process 官方 API](https://developer.android.com/reference/android/os/Process)、[SystemClock 官方 API](https://developer.android.com/reference/android/os/SystemClock)、[ART Hprof writer 源码](https://android.googlesource.com/platform/art/+/master/runtime/hprof/hprof.cc) 和 [RFC 9112 framing 规则](https://www.rfc-editor.org/rfc/rfc9112.html#section-6.3)。测试使用仓库锁定的 Java 17 / Gradle / AGP / Kotlin；本机缺少的 SDK 34、NDK 27 与 CMake 3.22.1 由 Gradle 下载官方组件，依赖 verification 保持 strict。

HTTP 的 1 秒限制是可选正文排空循环预算；DNS/连接/请求写入/响应 Header 和 OEM disconnect 仍有各自的平台行为及连接/读取超时，不能把它当成整个 HTTP 交换统一总超时。
